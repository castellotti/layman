# glove v3 grant-state fixtures (copy)

A byte-for-byte copy of glove's `tests/fixtures/netobs-v3/`: one `~/.glove` tree (`home/`) per
grant state, generated by glove's `extensions/observe/tests/fixtures/generate.py`:

| Scenario | What it is |
|---|---|
| `observe-only` | observe grant (flows + transcripts), no filter grant |
| `observe-filter` | observe + filter: `control/<id>/rules.json`, enforced (`status.json` `rules.sha256`) |
| `observe-no-transcripts` | observe with `transcripts: false`: no `transcripts/` |
| `filter-revoked` | filter was granted and revoked: on disk it looks exactly like `observe-only` |
| `orphaned` | registry row whose session directory is gone; the export remains |
| `not-observable` | a registry row only, with no grants and no export |
| `claude-code` | observe grant for `harness: claude-code`: Claude Code's native transcript layout (`-work/<uuid>.jsonl` with a `WebFetch` call, `-work/<uuid>/subagents/agent-<id>.jsonl`) and `proxy` flows for WebFetch |

glove creates `control/` in every home; git cannot keep an empty directory, so it is absent here
(as it is in glove's repository) and the tests create it in their temporary copy. Read by
`../v3.test.ts`, `../../monitor/sources.test.ts` and `../../claude/watcher.test.ts`.

Do not edit these files (this one excepted). To refresh:

```bash
rsync -a --delete --exclude COPIED.md ../glove/tests/fixtures/netobs-v3/ packages/server/src/netobs/__scenarios_v3__/
```

then update the date and commit above. `v3.test.ts` has a drift guard that fails when this copy
differs from glove's (skipped when glove is not checked out next to this repo).
